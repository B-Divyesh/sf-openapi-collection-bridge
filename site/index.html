How it works

Convert, review, then import

  1. Choose the source and destination.The CLI detects known files and Bruno folders.
  2. Convert with credentials removed.Named placeholders replace credential-shaped values by default.
  3. Review the evidence report.Check preserved, transformed, and unsupported rows before importing.

Privacy and limits

Know what the tool does not do

  • It does not execute API requests.
  • It does not sync or store collections.
  • It makes no conversion network requests.
  • Browser demo input clears on reload.
  • Destination clients still require a final review.
