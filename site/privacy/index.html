Privacy for local collection conversion

Your API definitions and collections stay on your device during conversion.

CLI data

The CLI has no telemetry. It makes no network requests and writes only the output paths you choose.

Browser demo data

The demo converts content in memory. It does not upload, log, or retain files. Reloading clears the input.

License data

If you enter a Pro license, this site stores the token and verification time in local storage.

The token goes only to the Sociobot billing API. Verification runs at most once each day.

Remove the stored license through your browser’s site-data controls.

Payments

Sociobot/Dodo handles checkout as merchant of record. Its checkout terms cover payment details.

Privacy requests

The converter has no account record to retrieve. For payment requests, use the contact option on your Sociobot receipt.

For site questions, open an issue in the public source repository ↗. Never include credentials or private API definitions.
